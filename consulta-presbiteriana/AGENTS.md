# Continuidad del proyecto

- El archivo principal de entrega es **consulta_presbiteriana.zip**. Conservar ese nombre y actualizar el mismo archivo existente cuando se guarde una entrega.
- Antes de entregar modificaciones, ejecutar `npm run entrega`: regenera documentos, ejecuta pruebas, compila, comprueba el arranque y actualiza el ZIP. Si falla una comprobación, corregirla antes de reemplazar la entrega vigente.
- El ZIP principal incluye código, compilación, documentos, PDF originales e iniciadores locales. Enlazarlo en la respuesta final para que siempre sea fácil encontrarlo.
- Mantener separados el texto normativo y las observaciones editoriales. Los cinco grupos documentales restantes requieren las fuentes o interpretaciones identificadas; no cerrarlos por inferencia ni confundir el cierre de las candidatas automáticas con aprobación oficial.
